# Quiz Project (Python)

A simple quiz program written in Python.

## About
This project asks the user a series of questions, checks the answers, and shows the final score.

## How to run
1. Make sure Python 3 is installed.
2. Download project1.py.
3. Run it from the terminal:

   python project1.py

## Features
- Multiple questions
- Score calculation
- Simple and easy to use
